This dashborad explores the dataset of the Energy mix of France for electricity production. It is from the official government website (https://www.data.gouv.fr/datasets/donnees-eco2mix-nationales-consolidees-et-definitives)

On the left side bar, you can chose the date range, starting from January 2011 to January 2026.
You can also chose if the time is divided by day, month or year, allowing to see different things on the same graph.
This will apply only on graphs that are not fixed.

At the end of the dashboard, there is small and simple simulation for the next years where we can try different scenarios concerning the CO2 production and the energy consumption.





To start the app, simply run the folloiing command in a terminal when located in the main folder of the project :

streamlit run App.py



Make sure the libraries indicated in requirements.txt are installed in your environnement, or simply run this command :

pip install -r requirements.txt
